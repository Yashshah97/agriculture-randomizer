# Usage

```python
import agriculture_randomizer
```

Each module is self-contained; see docstrings for the API:

- `agriculture_randomizer.core` — Core Monte Carlo engine logic and data structures
- `agriculture_randomizer.experiment` — Monte Carlo experiment runner with confidence intervals
- `agriculture_randomizer.data` — Crop yield and soil sensor data handling and simulation
- `agriculture_randomizer.utils` — Helper functions for Monte Carlo engine operations
- `agriculture_randomizer.tests_test_core` — Unit tests for core Monte Carlo engine logic
- `agriculture_randomizer.models` — data classes for the domain objects
